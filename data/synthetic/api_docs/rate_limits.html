Rate limits

When a client exceeds a quota, the API returns HTTP 429 Too Many Requests. Responses may include Retry-After, X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset headers.

Recommended client behaviour

Honor Retry-After and use bounded exponential backoff with jitter. Do not issue immediate retry bursts. Quota increases must be requested from the API owner and are outside automated diagnosis scope.
